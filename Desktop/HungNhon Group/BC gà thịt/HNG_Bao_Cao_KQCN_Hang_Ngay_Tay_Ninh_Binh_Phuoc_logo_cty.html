Dữ liệu Excel mẫu đã tích hợp
HNG Farms · Báo cáo KQCN gà thịt · Số liệu minh họa ban đầu là dữ liệu thực từ các file Excel được cung cấp. Chưa có dữ liệu cảm biến không đồng nghĩa với trạng thái bình thường. Các chỉ tiêu BW, FCR và BPI chỉ tính trên các trại có đủ số đo.

⚙ Kết nối Google Sheets

Thử kết nối
Thiết lập lần đầu: Chuyển 2 file Excel thành 2 Google Sheets. Bật Google Sheets API trong Google Cloud và tạo một API key. Với kết nối API key, Google Sheets phải cho phép đọc công khai (ví dụ “Bất kỳ ai có đường liên kết — Người xem”); file riêng tư cần OAuth hoặc proxy có xác thực. Nên hạn chế API key theo HTTP referrer của trang GitHub Pages và chỉ bật Google Sheets API. Không đưa key vào mã HTML trên GitHub.
Cảnh báo: API key phía trình duyệt không phải bí mật tuyệt đối. Chỉ sử dụng cho Google Sheets không chứa thông tin nhạy cảm.
Chưa kết nối. Dữ liệu Excel được nhúng sẵn để bạn xem báo cáo ngay.
